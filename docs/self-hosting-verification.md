## 运行限制

当前为单实例 Node 服务；内存缓存和限流在重启时清空，多副本不共享。公网浏览器定位需要 HTTPS。添加外层代理时按部署文档限定可信来源，否则访客可能共享代理 IP 的限额。用户浏览器旧域名的城市偏好不会自动迁移到新域名。
