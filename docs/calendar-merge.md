# 天气与日历合并

目标：在原天气站点切换天气与日历，选择日期后查询同一城市当天天气，再返回原日期。

来源：天气远端提交 `4ef0cbe74eb6986b1458c4569528f4bd350ff955`；日历远端提交 `3e411cf1c9bf5de6c69055843bd5945e74f27679`。工作目录是新拉取的远端副本。

设计决定：沿用天气框架、视觉和城市偏好；原日历核心算法、官方数据、键盘操作与回归样本保留，界面转为同站组件。顶部提供双视图切换，日期详情提供“查看当天天气”。日期详情不自动抢焦点，返回保留月份和日期。

边界：历史天气使用官方 `/v7/historical/weather`，支持过去十天且不含今天；预报沿用现有十日接口。超范围、无城市、无权限、无返回数据和请求失败均明确展示，不用当天数据代替。日历“今天”按北京时间，天气日期按城市时区。服务器凭据只保留在 Sites 环境变量。

官方接口核验日期：2026-10-20。参考 https://dev.qweather.com/docs/api/time-machine/time-machine-weather/ 。
